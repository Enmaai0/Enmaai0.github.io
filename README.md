## 📝 项目概述 | Introduction

项目使用React框架构建，结合Vite作为构建工具。
This project is a personal blog built using React and Vite.

## 📋 功能 | Functionality

- **首页**：展示博客概览和最近学习内容
- **项目展示**：展示个人项目作品集
- **资源链接**：收集和分享有价值的技术资源
- **Start page**：Show the overview of the blog and recent learning content
- **Project showcase**：Showcase personal project portfolio
- **Resource links**：Collect and share valuable technical resources

## 🚀 快速开始

### 环境要求

- Node.js 18.0.0+
- npm 9.0.0+

### 安装步骤

```bash
# 克隆项目
git clone https://github.com/yourusername/tech-blog.git

# 进入项目目录
cd tech-blog

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

### 构建部署

```bash
# 构建生产环境版本
npm run build

# 本地预览生产构建
npm run preview
```
